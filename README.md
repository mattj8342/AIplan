# AI Learning & Agent Portfolio Plan

A ten-week nightly plan for building practical AI skills, earning credentials, and creating an analytics agent portfolio.

**[Start here: the full nightly plan and 70-task checklist →](PLAN.md)**

## How to use the plan

1. Start at Week 1, Night 1 and work through one night at a time.
2. Save the result named in each task: notes, a working example, a commit, or an assessment outcome.
3. Change `- [ ]` to `- [x]` in [PLAN.md](PLAN.md) when that night's result is complete.
4. Use each weekly review to catch up and adjust the next week. Exam dates depend on readiness.

This repository begins with planned, unchecked tasks. Credentials and course completions are goals until earned.

## Learning and credential goals

- LinkedIn Learning: [Give Your AI Agent Skills](https://www.linkedin.com/learning/give-your-ai-agent-skills).
- LinkedIn Learning: [Agentic AI: Build Your First Agentic AI System](https://www.linkedin.com/learning/agentic-ai-build-your-first-agentic-ai-system).
- Microsoft Applied Skills: [Generate reports with AI research agents](https://learn.microsoft.com/en-us/credentials/applied-skills/generate-reports-with-ai-research-agents/).
- Microsoft Certified: [AI Transformation Leader — AB-731](https://learn.microsoft.com/en-us/credentials/certifications/ai-transformation-leader/).
- [LangChain Certified Agent Engineer](https://academy.langchain.com/pages/certifications-lcae), including the five listed prerequisite courses.

Course certificates of completion, Applied Skills credentials, and exam certifications are recorded using their exact issuer titles. The full plan includes resources, readiness checks, and LinkedIn visibility milestones. Confirm current requirements and pricing before enrolling or booking.

## Portfolio project

**Monthly Revenue Review Agent**

An agent that uses verified calculation tools to explain monthly revenue changes, identify customer and product contributions, and suggest what a manager should investigate.

The project uses synthetic data and includes expected answers, evaluation results, setup instructions, and a short demonstration. Its code is planned for a separate repository named `monthly-revenue-review-agent`; this repository holds the learning plan.
